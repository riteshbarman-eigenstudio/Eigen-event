The problem

Running one event takes six tools and a lot of copy-paste.

Forms + sheets

Registrations live in a spreadsheet nobody trusts.

Ticket site

Fees on every sale, little control over the page.

Email tool

Lists exported by hand before every reminder.

Video links

Join links pasted into agendas and chats.

Check-in app

A separate tool with a separate guest list.

Reporting

Numbers stitched together after the event ends.

6 → 1

Eigen Event puts the whole event in one workspace, with one guest list and one set of numbers.

Eigen Event: the whole event lifecycle, end to end.

How it's built

A simple, proven stack that one small team can ship.

Clients

Web app & PWA

Organizer console, public event pages, attendee app, scanner

Core

API & services

Events, ticketing, attendees, messaging, check-in, reporting

Data

Database & storage

Relational DB, file storage for images and badges, cache

Async

Queues & workers

Email, SMS, exports, webhooks

External

Payments, video, mail

Via provider integrations

The demo runs in the browser and saves to local storage. The API, database and payments replace that layer next. Design goals: one tenant per organization, API-first, mobile-first, offline-capable scanner.
